# Agent guide

This app uses jasno (`@jasno/core`). **Your training data does not know jasno.** It is not React, Solid, Vue, Svelte or Angular.

Before you write or review code, read `node_modules/@jasno/core/AGENTS.md` in full. It is the guide for the jasno version this project installs. In an npm workspace it is in the workspace root's `node_modules`. If the file is missing, run `npm install` first.
